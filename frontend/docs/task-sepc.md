# 任务模块说明

## 当前状态

- `src/views/task/MyTasksView.vue` 是“我的任务”模拟列表，支持前端状态筛选，尚未调用后端。
- `src/views/task/ProjectTasksView.vue` 已接入真实接口，挂载在 `/projects/:projectId/tasks`，包含：
  - 项目任务列表（列表 / 看板双视图，可切换），接 `GET /projects/{projectId}/tasks`。
  - 任务详情弹窗（使用列表返回的完整任务对象，暂无单独详情接口）。
  - 创建任务表单（校验、提交中状态、失败反馈、防重复提交），接 `POST /projects/{projectId}/tasks`。
  - 修改任务状态交互（列表行内下拉 + 看板卡片“移动到”菜单），接 `PATCH /tasks/{taskId}/status`，成功后用后端返回更新界面，失败保留原状态并提示。
  - 状态筛选、加载 / 空数据 / 失败重试 / 项目不存在等状态处理。
- 接口封装位于 `src/api/tasks.ts`，复用公共 Axios 实例；`TaskPriority` 类型补充在 `src/types/task.ts`。
- `/tasks` 表示当前用户跨项目的任务集合，与项目详情中的任务列表不同。
- 临时约定：创建任务暂无登录态，`creatorId` 默认取项目创建者 ID；负责人下拉选项由项目创建者与已有任务的负责人、创建者汇总，待成员接口就绪后替换。
- `src/views/project/ProjectTasksEntryView.vue` 占位页已不再被路由引用，与项目模块协调后可删除。
- 工作台仍依赖模拟任务，未修改公共模拟数据与公共 Axios 行为。

## 与项目模块的对接

- 建议将任务页面接到 `/projects/:projectId/tasks`，从路由参数获取项目 ID。
- 项目模块负责详情外壳、概览和成员入口、任务入口及子路由出口；任务模块负责任务内容区域。
- 页面不重复包含侧栏、顶部栏或项目详情外壳。
- 路由命名、参数和集成时间需提前协调；公共路由文件避免双方同时大幅修改。
- `/tasks` 的“我的任务”是否一并接手需明确。可复用任务组件，但不能把单个项目任务当作全部个人任务。

## 接口与数据约定

以[前后端 API 规范](../../docs/api-spec.md)为准，建议新增 `src/api/tasks.ts`，复用公共 Axios 实例：

```text
GET   /projects/{projectId}/tasks   项目任务列表
POST  /projects/{projectId}/tasks   创建任务
PATCH /tasks/{taskId}/status        修改任务状态
```

- Axios 已配置 `/api` 前缀。当前返回完整响应，业务数据位于 `response.data.data`，同时检查业务码。
- 当前没有单独的任务详情接口，可先使用列表返回的完整任务对象展示详情。
- 状态使用 `TODO`、`IN_PROGRESS`、`DONE`，优先级使用 `LOW`、`MEDIUM`、`HIGH`；前端显示中文。
- 创建任务当前需要临时提供 `creatorId`；负责人有值时必须是项目成员，成员选项来源需与项目模块、后端协商。
- 完成时间由后端维护。创建成功后刷新列表，状态修改成功后用后端返回的任务更新界面。
- 当前没有“我的任务”聚合接口，接入真实数据前需明确方案。
- 工作台仍依赖模拟任务，不直接删除公共模拟数据，也不擅自修改公共 Axios 行为。

## 交付检查

- 项目切换后正确加载对应任务，不残留上一个项目的数据。
- 列表、详情、创建结果及状态修改结果一致，筛选结果正确。
- 加载、空数据、失败和表单校验状态清晰。
- 运行 `npm run lint:check`、`npm run format:check`、`npm run build`，并手动验证完整交互。
- 交接时说明已接入接口、仍使用模拟数据的部分及未解决事项。
